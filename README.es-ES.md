# waywe

### Fondo de pantalla dinámico en Wayland, basado en Wallpaper Engine y mpvpaper

# Por qué

Es frustrante que Wallpaper Engine no admita Linux. Por eso escribo este sencillo script para cargar videos de Wallpaper Engine y reproducirlos con [mpvpaper](https://github.com/GhostNaN/mpvpaper).

# Uso

```
Uso: waywe [opciones] [comando]

Opciones:
  -h, --help       mostrar ayuda para el comando

Comandos:
  iniciar [opciones]  iniciar waywe
  enviar <comando>
  adjuntar           adjuntar al control interactivo de mpv
  detener
  reanudar
  pausar
  siguiente
  vista previa
  ayuda [comando]   mostrar ayuda para el comando

```
